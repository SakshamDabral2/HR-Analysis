## Project Overview

This project focuses on analyzing an HR dataset to gain meaningful insights into employee demographics, workforce distribution, employee performance, salary, recruitment, attendance, satisfaction, and termination trends. The analysis was performed using **SQL**, with the dataset stored in a table named `hrdata`.

The project involves answering business-focused questions using SQL concepts such as **SELECT, WHERE, GROUP BY, ORDER BY, HAVING, aggregate functions, CASE statements, date functions, and JOINs**.

## Key Areas of Analysis

* Employee and department distribution
* Salary analysis across departments and job positions
* Gender and marital-status distribution
* Employee age calculation using Date of Birth
* Employee termination and attrition analysis using `Termd` and `DateofTermination`
* Job satisfaction and employee engagement analysis
* Performance score analysis
* Recruitment source effectiveness
* Employee attendance and lateness analysis
* Manager and team analysis
* Hiring and termination trends over time
* Employee tenure analysis

## SQL Concepts Used

* Data Filtering using `WHERE`
* Data Aggregation using `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`
* Data Grouping using `GROUP BY`
* Sorting using `ORDER BY`
* Conditional Logic using `CASE`
* Date Functions such as `YEAR()`, `DATEDIFF()`, and `TIMESTAMPDIFF()`
* Subqueries
* JOIN operations for relational data analysis

## Business Objective

The objective of this project is to transform raw HR data into meaningful business insights. The analysis helps identify workforce patterns, understand employee termination, evaluate employee satisfaction and performance, analyze recruitment sources, and support data-driven HR decision-making.

## Tools Used

* **SQL**
* **MySQL**
* **HR Analytics Dataset**

This project demonstrates practical SQL skills and the ability to analyze employee data to generate actionable business insights.
